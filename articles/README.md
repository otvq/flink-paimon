# 发布级文章

**用途**：跳槽弹药库的主体（6–8 篇深度文），从草稿到发布到传播记录。文章是"知识转换而非知识陈述"（第3章）：写作过程反过来重塑理解。

**放什么**：每篇一个文件，头部维护元信息：
```
标题：
状态：草稿 / 已发布 / 已分发
发布链接：掘金 / 知乎 / 公众号
互动记录：阅读量、评论（≥1 条实质互动 = 技能树通过标准）
```

**命名**：`{序号}-{标题}.md`，如 `01-Flink2.0 barrier 流动全解析.md`。

**规划**（roadmap 阶段 7，随各阶段积累）：checkpoint 源码 ×2–3、Paimon LSM/compaction ×2、湖仓实战 ×1–2、AI 数据底座 ×1–2。W8 的故障实验记录 → 第一篇深度文，从这里开始。
