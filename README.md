> 本文件是项目的**上下文入口**：任何一次新会话（人或 AI 陪练）从这里开始，30 秒恢复全部上下文。最后更新：2026-11-12。

## 项目是什么

30 岁 / 3 年大数据 + 3 年 Java 的工程师，用 28 周（2026-11-12 → 2027-05 下旬）完成向"数据基础设施 / AI 数据底座工程师"的关键一跳（2026-11-12 补充 AI 阶段后由 24 周扩为 28 周）。终点：45 分钟白板讲透 Kafka → Flink → Paimon → StarRocks 完整数据生命周期及每步故障，含向量库/RAG 派生管线的一致性扩展题。

## 陪练会话怎么跑（日常练习循环）

用户说"今天练什么 / 陪练"时：

1. 读 `practice/练习日志.md` 顶部"当前唯一焦点" + 最后 3 行日志（热身 5 分钟）
2. 按 roadmap 当周主题 + 方案第 4 节选一个练习，确认难度在甜蜜点（费劲但够得着）
3. 练 25–50 分钟，只练这一个焦点
4. 三个 F 复盘（Focus / Feedback / Fix it），把结论追加进练习日志，更新"当前唯一焦点"
5. 周末会话额外跑：故障实验室 / 富兰克林文章复现 / 里程碑自测 / 产出物写作

用户报告"没进步/卡住/想放弃"时：按方案第 6 节停滞预案执行（加压暴露弱点 → 定位最小单元 → 微练习 → 换方向不加强度）。

## 铁律

- 每周必须有产出物（笔记/文章/代码），只看不写 = 没学
- 任何练习必须能回答：练什么 / 怎么算成功 / 反馈从哪来
- 单次专注 ≤1 小时；睡眠是练习的一部分
- 低于 8h/周 → 整体计划顺延 25%，不自责
