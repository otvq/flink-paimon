# 每周复盘

**用途**：每周日 10 分钟，雷打不动。这是"看见进步"的机制（第6章丹计划：数据化记录让进步可见）。

**每周固定动作**：
1. 更新 roadmap 里的打卡表（本周完成任务 + 产出物链接）
2. 把练习日志里本周"暴露的错误"归类：概念不清 / 链路断点 / 手误 / 场景误判——**同一类连续三次不犯才清除**，还犯的进下周微练习
3. 检查时间预算：本周实际专注几小时？低于 8h 则整个计划顺延 25%（顺延不自责）
4. 写一篇 `W{nn}-复盘.md`：本周最大收获 / 最大坑 / 下周唯一焦点

**命名**：`W{nn}-复盘.md`，如 `W01-复盘.md`。
