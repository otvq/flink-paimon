# 白板自测（练习 4 + 基线/里程碑自测）

**用途**：以讲代读。对一道题白板讲 15 分钟并录音，回听自评——录音回放是说话类技能的"录像自评"反馈（第5、6章）。

**放什么**：
1. 录音文件（或转写要点）
2. `W{nn}-{题目}-自评.md`：回听后写下自评修正清单（哪里卡壳、哪里讲错、哪里逻辑断了）

**三类自测都在这**：
- **W1 基线自测**：面试清单 10 题摸底（能讲/模糊/空白三档），产出技能树"当前水平"列 + 薄弱自查
- **阶段里程碑自测**：每个阶段结束跑一次，通过才进下一阶段
- **W27 面试清单全量自测**：每题白板 15 分钟

**价值**：每 4 周回听一次 W1 基线录音，是进步的可听证据。
