# 故障实验室（练习 3：注入故障 → 排查）

**用途**：自己制造故障再排查调优。**注入的故障就是标准答案**，是本领域最好的自带反馈练习。

**放什么**：一次实验一份记录，用统一模板：
1. **注入了什么**（故障配置/代码）
2. **观察到了什么**（metrics / 日志 / 现象）
3. **我的定位过程**（假设 → 验证 → 排除了什么）
4. **根因与解法**（≥2 种解法及适用条件）
5. **指标前后对比**（调优证据）

**命名**：`W{nn}-{故障名}.md`，如 `W08-慢checkpoint.md`。

**重点周次**：W8（慢 checkpoint / barrier 超时 / 状态膨胀）、W11（反压）、W16（compaction 风暴 / 小文件）、W19（向量-源文档不一致）。实验记录直接喂给对应文章（W8 第一篇深度文就在这里长出来）。
