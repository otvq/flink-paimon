# 断点追踪（练习 1：预测-断点验证）

**用途**：本方案的核心反馈回路。动手打断点之前，先在这里写下预测，再用断点实测，预测与实际的每个分岔点 = 心理表征缺口（第3章）。

**放什么**：每周源码主题一份记录文件，含三段：
1. **预测**（断点前写）：这条数据/这次调用会经过哪些类和方法？我预计会看到什么？
2. **实测**（断点后写）：实际调用栈关键帧（贴栈或截图）。
3. **分岔点分析**：预测错在哪？为什么范本/源码那样设计？

**命名**：`W{nn}-{主题}.md`，如 `W02-提交链路.md`（周号两位数，保证排序）。

**来源周次**：W1 起每周（工作日 1h 主练习）；W17–20 AI 阶段改为 API 行为预测-实测（faiss/pgvector 实验记录）。
