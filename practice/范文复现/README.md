# 范文复现（练习 2：富兰克林法）

**用途**：用富兰克林学写作的方法提升文章能力（第6章）：研究范本 → 凭线索复现 → 对比差距 → 修正重试。一次只攻一个维度（结构 → 论证深度 → 图示表达）。

**放什么**：每轮复现一组文件：
1. `范文-{标题}-线索.md`：读范文时只列每节内容线索（不抄正文）
2. `复现-{主题}-v{n}.md`：隔 2 天后凭线索自己重写的稿子
3. 同文件尾部附**差距清单**（逐节对比：我的论证浅在哪？图示差在哪？）——下一轮同维度差距不复发才算过关

**命名**：按上述前缀，主题内递增版本号。

**时机**：W8 前选 1 篇 Flink checkpoint 佳作、W16 前选 1 篇 Paimon LSM 佳作（候选来源见 roadmap 参考资料），周末执行。
